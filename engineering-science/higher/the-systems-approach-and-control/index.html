The systems approach & control

8 cards · 7 quiz · 0 exam

Engineering Science · Higher · mrkellydt.co.uk

Input, process, output

Any system can be shown as a universal system diagram: input → process → output. A sub-system diagram breaks the process into blocks (e.g. sensor → control → driver → motor), with arrows showing the signal or energy passing between them.

In exam diagrams use the general words input, process and output where asked. The 2025 report noted that specific labels such as "user input" or "output energy" scored nothing on a universal system diagram.

Finding inputs and outputs

To fill in a universal system diagram, ask two questions:

  • Input: what do I have to do to make it work? (e.g. switch it on, add fuel, press a button)
  • Output: what does it do? (e.g. hot water, rotary movement, light)

You can also show the energy going in and out: a kettle turns electrical energy into heat (thermal) energy; a car turns chemical energy into kinetic energy.

Sub-system diagrams, boundary and driver

A sub-system diagram breaks the process into parts. Draw a dashed box round it: this is the system boundary. Anything inside is part of the system; anything outside is the outside world (the user, the room).

Most Engineering Science systems follow the same pattern:

  • Control unit: usually an electronic circuit that makes decisions.
  • Driver: amplifies the small signal from the control unit so it can power the output (e.g. a transistor or relay). A driver is always needed before a motor, lamp or heater.
  • Output: usually a motor, lamp or heater.
  • Feedback sensor (closed loop only): usually a light, temperature or speed sensor.

Always draw proper arrowheads to show the direction of each signal.

Open and closed loop control

  • Open loop: no feedback. The system does what it is set to do and doesn't check the result, e.g. a toaster on a timer.
  • Closed loop: a sensor measures the actual output and feeds it back; the controller compares the actual level with the set (desired) level and adjusts the output, e.g. a thermostat-controlled heater.

When describing a closed-loop system, include all three: the sensor measuring the actual output and feeding back; the control sub-system comparing set and actual; and the specific action on the output ("the heater switches on when the temperature is below the set level and off when above"). Write "closed loop control", not just "closed".

Describing a closed loop system: four steps

  1. Say whether it is open or closed loop (most exam systems are automatic and closed loop).
  2. The user sets the required value (the set value, or reference value), e.g. 21 °C, and the system starts producing its output.
  3. The feedback sensor measures the actual value and feeds it back to the control unit.
  4. The control unit compares the actual value with the set value and adjusts the output to match, e.g. switches the heater off when 21 °C is reached.

Name the real sensor and output in the question: "the thermistor measures the room temperature", not just "the sensor". A speedometer only displays speed; a speed sensor measures it.

Feedback, error and types of control HIGHER

  • Negative feedback: the feedback signal is subtracted from the set value at a comparator (summing point) to give an error signal. The controller acts to reduce the error to zero.
  • Two-state (on/off) control: the output is either fully on or fully off. Simple and cheap, but the output overshoots and oscillates about the set point, giving uneven motion or temperature.
  • Proportional control: the output is proportional to the size of the error, so the system slows as it approaches the set point, giving a smoother response with less overshoot.
  • A response graph for proportional control shows a quick initial response, the error reducing over time, and the system settling at (or near) the set point.

Control diagrams may include a gain: e.g. output = gain × (set − feedback). Rearrange to find the feedback voltage: 8.0 = 4 × (3.2 − Vf) gives Vf = 1.2 V.

Positive feedback and gain HIGHER

  • Positive feedback adds to the error instead of reducing it, so the output runs away, e.g. the howl when a microphone is held near its speaker. Control systems use negative feedback.
  • Two-state (comparator) control has a time lag: the heater stays hot after switching off, so the temperature overshoots and then undershoots the set level.
  • Proportional control uses a difference amplifier: a big error gives a big output and a small error a small one, so the output eases off as it approaches the set level.
  • The gain matters: low gain responds slowly; high gain responds quickly but overshoots before settling. Engineers adjust it for a fast response with little overshoot.

What catches people out

  • Didn't link "why two-state control is unsuitable" to the scenario. Say what goes wrong in this situation: e.g. the temperature overshoots, or the motor jerks on and off. H 2024

Key terms

Universal system diagramInput → process → output.
Sub-systemOne block of a system, e.g. sensor, controller, driver, output device.
Open loop controlNo feedback: the output is not checked.
Closed loop controlA sensor feeds back the actual output; the controller compares it with the set level and adjusts.
FeedbackThe signal from the output returned to the input/controller for comparison.
Error signalSet value minus feedback value, found at the comparator.
Two-state controlOutput fully on or fully off; causes overshoot and oscillation.
Proportional controlOutput proportional to the error; smoother, less overshoot.

Quick check

1. Raising the gain in a proportional control system usually makes it…

  1. Respond more slowly
  2. Respond faster but overshoot
  3. Stop working
  4. Open loop
Show answer
B: Respond faster but overshoot. High gain: quick response, overshoot.

2. A microphone howling near its speaker is an example of…

  1. Negative feedback
  2. Positive feedback
  3. Open loop
  4. Two-state control
Show answer
B: Positive feedback. The error is reinforced.

3. A toaster that pops up after a fixed time is…

  1. Closed loop
  2. Open loop
  3. Proportional
  4. Negative feedback
Show answer
B: Open loop. No measurement of the toast.

4. In a closed-loop heater, which component measures the actual temperature?

  1. Heater
  2. Relay
  3. Temperature sensor
  4. Comparator
Show answer
C: Temperature sensor. The sensor feeds back the actual level.

5. On a universal system diagram, the middle block is labelled…

  1. Control
  2. Process
  3. Driver
  4. Sensor
Show answer
B: Process. Input, process, output.

6. Which control type gives the smoothest approach to the set point?

  1. Open loop
  2. Two-state
  3. Proportional
  4. None
Show answer
C: Proportional. Output reduces as the error reduces.

7. At the comparator, the error signal is…

  1. Set + feedback
  2. Set − feedback
  3. Feedback × gain
  4. Output ÷ input
Show answer
B: Set − feedback. Negative feedback is subtracted.
