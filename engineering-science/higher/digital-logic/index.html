Notes

Logic gates

  • AND: output 1 only when all inputs are 1. Boolean A·B.
  • OR: output 1 when any input is 1. A+B.
  • NOT (inverter): output is the opposite of the input. Ā.

Truth tables list every combination of inputs: 2 inputs = 4 rows, 3 inputs = 8 rows. Work through a logic diagram column by column, labelling the intermediate points (D, E, F) as SQA does.

From a written problem to a logic circuit

Pick out the conditions: "the alarm sounds when the door is open AND the system is armed, OR the panic button is pressed" gives Z = (A·B) + C. Draw each gate with all its input connections, and wire the final gate to the output. NOT gates come first on the input they invert.

Boolean expressions and truth tables

Write the expression one gate at a time, from the inputs to the output. A NOT gate on A gives Ā; Ā into an OR gate with B gives (Ā + B); that into an AND gate with C gives Z = (Ā + B)·C. Use brackets to show which gate comes first.

For a truth table, add a column for each point in the middle of the circuit, and work out that column before the output. Example: Z = (A·B) + C, with M = A·B.

NAND, NOR and EOR

  • NAND: NOT AND: output 0 only when all inputs are 1.
  • NOR: NOT OR: output 1 only when all inputs are 0.
  • EOR (exclusive OR): output 1 when the inputs are different.

NAND equivalents: any gate can be built from NANDs: NOT = NAND with inputs joined; AND = NAND followed by a NAND-NOT; OR = NAND-NOTs on each input then a NAND. Convert the whole circuit, then cancel any two NOTs in a row (double inversion) to use the fewest gates. The 2025 Higher assignment report: many didn't reduce to the fewest gates.

Derive Boolean expressions from truth tables, diagrams or specifications with up to four inputs, using brackets: e.g. Z = NOT(A + B) + B·C.

Boolean from a truth table

  1. Find every row where the output is 1.
  2. For each one, write an AND term using every input: write the input if it is 1 and NOT the input if it is 0. E.g. A = 0, B = 1, C = 1 gives Ā·B·C.
  3. OR the terms together: e.g. Z = Ā·B·C + A·B·C̄.
  4. Draw the circuit straight from the expression, then convert to NAND gates if asked.

With 4 inputs a truth table has 24 = 16 rows. Circuits are often built from NAND gates because one type of IC (for example a chip with four 2-input NANDs) can make any function, so fewer types of chip are needed and costs fall.

Quick check

1. NOT A into an OR gate with B, then AND with C gives…

  1. Z = Ā + B·C
  2. Z = (Ā + B)·C
  3. Z = Ā·B + C
  4. Z = (A + B)·C
Show answer
B: Z = (Ā + B)·C. Work gate by gate, using brackets.

2. Z = (A·B) + C. When A = 1, B = 0, C = 0, Z is…

  1. 0
  2. 1
  3. Undefined
  4. 2
Show answer
A: 0. A·B = 0 and C = 0.

3. Z = 1 only when A = 0 and B = 1. The Boolean expression is…

  1. A·B
  2. Ā·B
  3. A + B̄
  4. Ā + B
Show answer
B: Ā·B. Invert the input that is 0.

4. How many rows does a 4-input truth table have?

  1. 8
  2. 12
  3. 16
  4. 4
Show answer
C: 16. 2⁴.

5. A=1, B=0 into an AND gate gives…

  1. 0
  2. 1
  3. Both
  4. Neither
Show answer
A: 0. All inputs must be 1.

6. A=1, B=0 into an OR gate gives…

  1. 0
  2. 1
  3. Undefined
  4. 2
Show answer
B: 1. Any input 1.

7. How many rows does a 3-input truth table have?

  1. 3
  2. 6
  3. 8
  4. 9
Show answer

8. Which gate gives 1 only when its inputs differ?
