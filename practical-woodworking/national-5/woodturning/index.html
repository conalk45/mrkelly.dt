Notes

Two ways to turn

  • Between centres: the wood is held between the drive centre (headstock) and the live/dead centre (tailstock). For long items: table legs, handles, knobs, spindles.
  • Faceplate turning: the wood is screwed to a faceplate on the headstock. For wide, flat items: bowls, plates, bases.

Preparing a blank for between centres

  1. Cut the blank square and a little longer than needed.
  2. Draw diagonal lines on each end: where they cross is the centre.
  3. Saw shallow cuts along the diagonals on one end so the drive centre's prongs grip and the wood doesn't slip.
  4. Plane off the corners to make it octagonal: it's safer and quicker to turn round.
  5. Mount it, tighten the tailstock, then set the tool rest just below centre height and close to the wood, and rotate by hand to check it clears.

Lathe tools

ToolUse
Roughing gougeTurns a square blank round
Spindle gougeShapes coves (hollows) and beads
Skew chiselSmooths cylinders and cuts beads and V-cuts
Parting toolCuts grooves to a set diameter and parts work off
ScraperFinishing cuts, especially in faceplate work

Check diameters with outside calipers set from a steel rule. Turned diameters must be within ±1 mm.

Lathe safety

  • Wear goggles or a visor; tie back hair; no loose sleeves, ties or jewellery.
  • Check the wood is secure and has no splits or loose knots.
  • Set the tool rest close and remove the chuck key / tommy bar before starting.
  • Rotate by hand first; start at low speed for large or unbalanced work.
  • Move the tool rest only with the lathe stopped. Remove it before sanding.

Quick check

1. Why are saw cuts made along the diagonals on one end of a blank?

  1. To decorate it
  2. So the drive centre grips and doesn't slip
  3. To make it lighter
  4. To find the length
Show answer
B: So the drive centre grips and doesn't slip. The prongs of the drive centre sit in the cuts.

2. Which method would you use to turn a bowl?

  1. Between centres
  2. Faceplate
  3. Pillar drill
  4. Mortiser
Show answer
B: Faceplate. Wide flat work is screwed to a faceplate.

3. Which tool turns a square blank round?

  1. Parting tool
  2. Roughing gouge
  3. Scraper
  4. Skew chisel
Show answer
B: Roughing gouge. The roughing gouge removes the corners quickly.

4. What should you always do before switching on the lathe?

  1. Sand the wood
  2. Rotate the work by hand to check it clears the tool rest
  3. Remove the tailstock
  4. Apply finish
Show answer
B: Rotate the work by hand to check it clears the tool rest. This checks nothing will catch.

5. How would you check a turned diameter?

  1. Try square
  2. Outside calipers
  3. Marking gauge
  4. Sliding bevel
Show answer
B: Outside calipers. Set the calipers from a rule and check as you turn.
