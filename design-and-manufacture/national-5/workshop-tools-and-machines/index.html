Plastic: mark on the protective film with pencil, or use a non-permanent spirit marker or masking tape. Mark out in the corner of the sheet to reduce waste. Templates speed up repeated marking.

Hand tools

  • Saws: tenon (straight cuts in wood), coping (curves in wood/plastic), hacksaw and junior hacksaw (metal and plastic).
  • Chisels: mortise (heavy chopping of mortises, hit with mallet), bevel-edged (accurate paring, dovetails).
  • Planes: jack (large areas), smoothing (finishing), rebate (cutting rebates), plough (grooves).
  • Hammers/mallets: claw (nails, removing nails), cross-pein (pins), ball-pein (metalwork, riveting); wooden mallet (chisels), hide mallet (shaping sheet metal without marking).
  • Drill bits: twist (general holes), Forstner (clean flat-bottomed holes in wood), countersink (screw heads flush), centre (starting holes on the lathe).
  • Also: files, hand router (levels housing joints), pliers, tin snips, pop-rivet gun, bending bars, taps and dies (internal/external threads), nail punch, bradawl (pilot holes in wood).

Machine tools

  • Pillar drill: secure work in a machine vice; set the depth stop for blind holes; guard down.
  • Centre lathe (metal): parallel and step turning, taper turning, facing, drilling, knurling (a grip pattern).
  • Wood lathe: prepare blank (remove corners), parallel turning, parting off, sanding and finishing on the lathe.
  • Mortise machine: cuts mortises accurately; set the depth stop.
  • Disc and belt sanders: shaping and smoothing.
  • Scroll/fret saw: intricate curves in thin material.
  • Strip heater: line bending acrylic. Oven: heating plastic or metal. Fluidiser: dip-coating hot metal in plastic powder.

Setting up the centre lathe: secure the bar in the three-jaw chuck with little overhang; remove the chuck key; set the tool at centre height in the tool post; set the spindle speed for the material and diameter; close the guard; check the work runs true. For taper turning, set the compound slide to the angle.

Holding tools

  • Woodwork bench vice, engineer's vice (use soft jaws for plastic), machine vice (drilling), hand vice (small parts).
  • G-clamp (holding work, gluing), sash cramps (gluing up large frames).
  • Jigs and formers: guide tools or shape parts accurately and repeatably.

Key terms

Marking gauge
Marks a line parallel to an edge on wood (one spur).
Mortise gauge
Marks two parallel lines for a mortise and tenon (two spurs).
Odd-leg callipers
Scribe a line parallel to the edge of metal.
Centre punch
Makes a dimple to locate a drill before drilling metal.
Coping saw
Cutting curves in thin wood or plastic.
Forstner bit
Drills clean, flat-bottomed holes in wood.
Knurling
Centre lathe operation creating a textured grip pattern.
Depth stop
Pillar drill/mortiser setting to control hole depth.
Taps and dies
Taps cut internal threads; dies cut external threads.
Strip heater
Heats a line on acrylic so it can be bent.

Quick check

1. Which tool marks a line parallel to the edge of a piece of metal?

  1. Marking gauge
  2. Odd-leg callipers
  3. Try square
  4. Bradawl
Show answer
B: Odd-leg callipers. Marking gauge is for wood.

2. Which tool would you use before drilling a hole in mild steel?

  1. Bradawl
  2. Centre punch
  3. Marking knife
  4. Mortise gauge
Show answer
B: Centre punch. The punch dimple stops the drill wandering.

3. Which saw is best for cutting a curve in 6 mm acrylic?

  1. Tenon saw
  2. Coping saw
  3. Hacksaw
  4. Panel saw
Show answer
B: Coping saw. Thin blade turns easily.

4. A flat-bottomed hole for a hinge recess in wood is drilled with a…

  1. Twist drill
  2. Countersink bit
  3. Forstner bit
  4. Centre drill
Show answer
C: Forstner bit. Forstner bits cut clean flat bottoms.

5. Which centre lathe process creates a diamond grip pattern?

  1. Parting off
  2. Knurling
  3. Facing
  4. Taper turning
Show answer
B: Knurling. Knurling rolls a pattern into the surface.

6. Which tool levels the bottom of a housing joint?

  1. Hand router
  2. Jack plane
  3. Rasp
  4. Tin snips
Show answer
A: Hand router. The hand router cleans out housings to depth.

7. How is a hole of a set depth drilled consistently on a pillar drill?

  1. Use a centre punch
  2. Set the depth stop
  3. Use a larger bit
  4. Use soft jaws
Show answer
B: Set the depth stop. The depth stop limits travel.

Exam-style questions

1. Describe how the centre lathe would be set up and used to taper turn a mild steel handle. (4 marks)

Show marking guidance
  • Secure the bar in the three-jaw chuck (1)
  • Set the compound slide to the required angle (1)
  • Set tool at centre height and check guards/safety (1)
  • Wind the compound slide to cut the taper in several passes (1)

2. Name two marking-out tools you would use to mark out a housing joint and state why. (2 marks)

Show marking guidance
  • Try square: lines across the grain at 90° (1)
  • Marking gauge: depth of the housing parallel to the edge (1)
  • Marking knife: cuts fibres for a clean saw line (1)
