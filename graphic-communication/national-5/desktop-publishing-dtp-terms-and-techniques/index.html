Desktop publishing (DTP) terms & techniques

9 cards · 5 quiz · 0 exam

Planning a layout

  • Thumbnails: small, quick sketches of layout ideas. They let you try a range of ideas fast and share them with the client.
  • Annotation: notes on thumbnails explaining decisions and how they meet the brief.

Layout terms

TermMeaning
MarginSpace between the edge of the page and the content
Column / gutterVertical blocks of text / the gap between columns
Text box, handlesA frame holding text / the squares used to resize or rotate an item
Title, heading, extended (body) text, captionMain heading / section headings / the main paragraphs / short text describing an image
Header and footerContent repeated at the top / bottom of pages
Text wrapText flowing around the shape of an image
Flow text along a pathText following a curved line
ReverseLight text on a dark background
Drop shadow / transparencyA shadow giving depth / an item made see-through so layers show below
CroppingRemoving unwanted parts of an image
JustificationHow text lines up: left, right, centred or fully justified
BleedColour or images extending past the trim edge so no white edge shows after cutting
Grid, guidelines, snapNon-printing lines that items snap to, for accurate alignment and spacing
Colour fill, rotate, lineFilling shapes with colour / turning items / rules dividing items

Fonts

  • Serif fonts have small strokes (serifs) at the ends of letters: traditional, formal, easy to read in long printed text.
  • Sans serif fonts have no serifs: modern, clean, informal, easy to read on screen and at a distance; they suit simple, modern designs and younger audiences.

When asked why a font suits a layout, link it to the theme or target audience.

Paper sizes

A-series sizes: each size is half the one before, with the same proportions (ratio 1 : 1.41). A4 is 210 × 297 mm; A3 (297 × 420) is double A4; A5 is half of A4. "Bigger" or "smaller" doesn't score when asked to compare: say double or half.

Benefits of DTP software

  • Grids, guides and snap give accurate alignment and spacing quickly.
  • Layouts can be changed and tried out quickly with real images.
  • A wide range of fonts, colours and effects (transparency, drop shadow, text wrap).
  • Output for both print and web.

Exam questions often ask you to describe DTP features in the given layout: point to where each is used. "Speeds up production" is a general benefit, not a layout feature, and scores 0.

What catches people out

  • Confused flow text along a path with text wrap, and column with gutter. Text wrap flows around an image; flow text along a path follows a line. The gutter is the gap between columns. N5 2025
  • Described general benefits of DTP ("speeds up production") instead of features in the layout. Point to where each feature is used in the given graphic. N5 2024
  • Couldn't name DTP techniques used in a layout. Learn the list: text wrap, reverse, drop shadow, bleed, transparency, cropping, flow text along a path. N5 2024

Quick check

1. The space between two columns is the…

  1. Margin
  2. Gutter
  3. Bleed
  4. Header
Show answer
B: Gutter. Gutter.

2. White text on a black box is…

  1. Reverse
  2. Transparency
  3. Drop shadow
  4. Bleed
Show answer
A: Reverse. Reverse.

3. Why does a designer extend the background past the trim edge?

  1. To use more ink
  2. So no white edge shows after cutting (bleed)
  3. To add a border
  4. To add a margin
Show answer
B: So no white edge shows after cutting (bleed). Bleed.

4. Text following a curved line uses…

  1. Text wrap
  2. Flow text along a path
  3. Justification
  4. Reverse
Show answer
B: Flow text along a path. Often confused with text wrap.

5. A sans serif font suits a modern layout because…

  1. It is formal and traditional
  2. It looks clean and modern and is easy to read
  3. It looks handwritten
  4. It is always bold
Show answer
B: It looks clean and modern and is easy to read. Link to theme/audience.
