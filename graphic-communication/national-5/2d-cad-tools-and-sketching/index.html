Notes

2D drawing tools

ToolWhat it does
Line, circle, arc, ellipse, rectangleDraw basic geometry
TrimCuts away parts of lines up to where they cross other lines
MirrorMakes a reflected copy about a line: draw half, mirror the rest
CopyDuplicates geometry
RotateTurns geometry about a point
ScaleMakes geometry bigger or smaller
ZoomChanges the view, not the size of the drawing
FilletRounds a corner with a set radius
ChamferCuts a corner off at an angle, e.g. 4 × 45°
Pattern fill (hatch)Fills an area with a pattern, e.g. section hatching

Exam questions show a sketch changing in stages and ask you to name the tool used at each stage: line, trim, mirror, rotate and scale come up most.

CAD libraries and import/export

A CAD library holds ready-made parts and symbols (nuts, bolts, bearings, doors, windows, sanitary ware). Using it saves time because parts aren't redrawn, and they are accurate and standard. Import brings in files such as images or another package's drawings; export saves to formats others can use.

Key terms

Trim
Removes parts of lines up to where they meet other lines.
Mirror
Creates a reflected copy about a line.
Fillet (2D)
Rounds a corner to a set radius.
Chamfer (2D)
Cuts a corner at an angle.
CAD library
Ready-made standard parts and symbols; saves time and is accurate.

Quick check

1. Which tool removes the overlapping parts of crossing lines?

  1. Mirror
  2. Trim
  3. Scale
  4. Copy
Show answer
B: Trim. Trim.

2. A designer draws half a symmetrical shape. Which tool completes it?

  1. Rotate
  2. Mirror
  3. Fillet
  4. Zoom
Show answer
B: Mirror. Mirror about the centre line.

3. Which tool rounds a sharp corner?

  1. Chamfer
  2. Fillet
  3. Trim
  4. Extend
Show answer
B: Fillet. Fillet = radius.

4. Zoom changes…

  1. The size of the object
  2. The view only
  3. The scale on the drawing
  4. The line type
Show answer
B: The view only. It only changes how close you look.
