3D CAD modelling

4 cards · 3 quiz · 0 exam

Graphic Communication · National 5 · mrkellydt.co.uk

Modelling features

  • Extrude: a 2D profile pulled out to a set distance to make a solid.
  • Revolve: a profile rotated around an axis. State the axis and the angle: 360° for a full solid, or e.g. 90° for a quarter.

Modelling edits

  • Subtract (extrude subtract / cut): removes material, e.g. a hole or slot.
  • Add (union): joins solids.
  • Shell: hollows a solid to a wall thickness, removing chosen faces. State the thickness and the faces removed.
  • Fillet: rounds edges to a radius. Chamfer: bevels edges.

How to answer a "describe how to model" question

These are worth 4–7 marks and are where most of the marks are awarded. For each stage, write:

  1. the 2D profile (sketch) with its key sizes, and where it is drawn (which face or work plane);
  2. the feature command (extrude, revolve…) with the distance, angle or axis;
  3. any edit (subtract, shell, fillet, chamfer) with the size and which edges or faces.

Example: "Sketch a Ø50 circle and extrude 50. On the top face sketch a Ø35 circle and extrude-subtract 40. Fillet the bottom edge R2 and chamfer the top edge 2.5 × 45°."

  • Use the correct terms from the course specification: "cut out" or "pull up" are not awarded marks.
  • Include every relevant dimension; read them carefully off the drawing.
  • Get the order right: shell before adding internal features (in 2025 N5, shelling at the end was not awarded marks).
  • For a revolve, name the centre axis and the angle: both carry marks.

What catches people out

  • Didn't describe a 360° revolve around an axis, or forgot to subtract material. Revolve = profile + centre axis + angle. Holes and slots = sketch + extrude-subtract. N5 2024
  • Not awarded marks for the wrong order (shell last) or a wrong fillet size. Plan the order: shell before adding internal features; read every size off the drawing. N5 2025

Key terms

ExtrudePull a 2D profile out to a set distance to make a solid.
RevolveRotate a profile around an axis; state axis and angle.
ShellHollow a solid to a wall thickness, removing chosen faces.
Extrude subtractRemove material using a profile, e.g. for a hole or slot.

Quick check

1. A wine glass stem with a curved profile is best made with…

  1. Extrude
  2. Revolve
  3. Shell
  4. Chamfer
Show answer
B: Revolve. Revolve the profile 360° around the centre axis.

2. Which hollows out a solid to a wall thickness?

  1. Fillet
  2. Shell
  3. Chamfer
  4. Revolve
Show answer
B: Shell. Shell, removing chosen faces.

3. For a revolve, which TWO things carry marks?

  1. Colour and material
  2. Centre axis and angle
  3. Fillet and chamfer
  4. Work plane and zoom
Show answer
B: Centre axis and angle. Both are needed.
