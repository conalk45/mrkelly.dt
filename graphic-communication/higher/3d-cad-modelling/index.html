3D CAD modelling

10 cards · 7 quiz · 0 exam

Graphic Communication · Higher · mrkellydt.co.uk

Modelling features

  • Extrude: a 2D profile pulled out to a set distance to make a solid.
  • Revolve: a profile rotated around an axis. State the axis and the angle: 360° for a full solid, or e.g. 90° for a quarter.
  • Loft (Higher): joins two or more different profiles on offset work planes, e.g. a circle to a smaller circle 80 mm above it.

Higher modelling features HIGHER

  • Extrude (sweep) along a path: a profile on a work plane perpendicular to the start of a path, swept along it. Give the path with all its dimensions and the profile size.
  • Helix: a profile offset from an axis (the offset is the helix radius) swept round in a spiral. Give any two of pitch (distance per turn), revolutions and height: e.g. 11 revolutions at pitch 20 gives a height of 220. The 2025 report noted many candidates mixed up pitch and revolutions.
  • Loft at Higher often combines with shell and offset work planes.

Modelling edits

  • Subtract (extrude subtract / cut): removes material, e.g. a hole or slot.
  • Add (union): joins solids.
  • Shell: hollows a solid to a wall thickness, removing chosen faces. State the thickness and the faces removed.
  • Fillet: rounds edges to a radius. Chamfer: bevels edges.
  • Higher adds intersect (keeps only the overlapping volume), mirror and array (linear, box, radial), and regular or irregular (variable) fillets and chamfers.

How to answer a "describe how to model" question

These are worth 4–7 marks and are where most of the marks are awarded. For each stage, write:

  1. the 2D profile (sketch) with its key sizes, and where it is drawn (which face or work plane);
  2. the feature command (extrude, revolve, loft…) with the distance, angle or axis;
  3. any edit (subtract, shell, fillet, chamfer) with the size and which edges or faces.

Example: "Sketch a Ø50 circle and extrude 50. On the top face sketch a Ø35 circle and extrude-subtract 40. Fillet the bottom edge R2 and chamfer the top edge 2.5 × 45°."

  • Use the correct terms from the course specification: "cut out" or "pull up" are not awarded marks.
  • Include every relevant dimension; read them carefully off the drawing.
  • Get the order right: shell before adding internal features (in 2025 N5, shelling at the end was not awarded marks); shell before a radial array of holes.
  • At Higher you don't need to describe the 2D commands used to draw a profile; the profile with all its sizes is enough.
  • For a revolve, name the centre axis and the angle: both carry marks.

Modelling terms and concepts HIGHER

  • Sketch / profile: the 2D shape a feature is made from. Work plane: a flat plane to sketch on, which can be offset from a face. Axis: a line to revolve around. Face, edge, vertex: the surfaces, lines and corners of a solid.
  • Feature: each operation in the model. Datum: a reference plane, axis or point. Suppress: temporarily switch a feature off.
  • Modelling tree (history): the ordered list of features. To change a model, edit the sketch or feature in the tree; the model updates. In 2024 a candidate who remodelled from scratch instead of editing the tree scored 0.
  • Modelling plan: the planned order of features before you start.

What catches people out

  • Helix: pitch and revolutions mixed up; path dimensions missing for extrude along a path. Pitch = distance per turn; height = pitch × revolutions. Give the path's full sizes. Higher 2025
  • Described the 2D commands for sketching profiles (no marks). Give the profile with all relevant sizes; marks are for the 3D stages. Higher 2024

Quick check

1. A wine glass stem with a curved profile is best made with…

  1. Extrude
  2. Revolve
  3. Shell
  4. Chamfer
Show answer
B: Revolve. Revolve the profile 360° around the centre axis.

2. Which hollows out a solid to a wall thickness?

  1. Fillet
  2. Shell
  3. Chamfer
  4. Revolve
Show answer
B: Shell. Shell, removing chosen faces.

3. Joining a large circle to a smaller circle on an offset plane is a…

  1. Revolve
  2. Loft
  3. Extrude
  4. Subtract
Show answer
B: Loft. Loft.

4. For a revolve, which TWO things carry marks?

  1. Colour and material
  2. Centre axis and angle
  3. Fillet and chamfer
  4. Work plane and zoom

B: Centre axis and angle. Both are needed.

5. A helix has pitch 10 and 12 revolutions. Its height is…

  1. 22
  2. 120
  3. 1.2
  4. 100
Show answer
B: 120. 10 × 12.

  1. Remodel from scratch
  2. Edit the sketch in the modelling tree
  3. Delete the model
  4. Scale it

B: Edit the sketch in the modelling tree. Edit in the tree.

7. Which Boolean keeps only the overlap of two solids?
