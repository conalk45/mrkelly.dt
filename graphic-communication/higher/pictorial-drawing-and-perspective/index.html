Notes

Isometric, oblique and planometric

ViewHow it is drawnUsed for
IsometricVerticals stay vertical; the other two axes at 30° to the horizontal. All three axes true length. Circles become ellipses.Products and components, exploded views
ObliqueFront face drawn true shape; depth lines at 45°. Cabinet oblique halves the depth so it looks right.Objects with curves or circles on the front face
PlanometricThe plan is drawn true shape, rotated (usually 45°/45° or 30°/60°); verticals drawn true height.Room and interior layouts, kitchens, gardens

Perspective

  • One-point perspective: the front face is drawn true shape; all depth lines go to one vanishing point (VP) on the horizon line. Good for interiors and views straight down a street or corridor.
  • Two-point perspective: the object is drawn corner-on; lines go to two VPs on the horizon line, verticals stay vertical. The most realistic, used for presentation of products and buildings.
  • The horizon line is eye level. Above it you see the underside; below it you see the top (bird's-eye view).

Drawing circles in isometric

Draw an isometric square (a crate) the size of the circle's diameter, mark the midpoints of each side and sketch the ellipse touching those points. For accurate drawing, transfer points from an orthographic view (ordinates). CAD does this automatically.

Key terms

Isometric
Verticals vertical, other axes at 30°, all true length.
Oblique
Front face true shape, depth at 45°.
Cabinet oblique
Oblique with the depth halved.
Planometric
Plan drawn true shape and rotated; verticals true height. Used for room layouts.
One-point perspective
One vanishing point; front face true shape.
Two-point perspective
Two vanishing points on the horizon line; verticals stay vertical.
Horizon line
Eye level in a perspective drawing.

Quick check

1. In isometric, the receding axes are at…

  1. 45°
  2. 30°
  3. 60°
  4. 90°
Show answer
B: 30°. 30° to the horizontal.

2. Which pictorial shows the front face in true shape with depth at 45°?

  1. Isometric
  2. Oblique
  3. Planometric
  4. Two-point perspective
Show answer
B: Oblique. Oblique.

3. Which view is best for showing the layout of a room?

  1. Oblique
  2. Planometric
  3. One-point perspective of a product
  4. Orthographic elevation
Show answer
B: Planometric. Planometric uses a true-shape plan.

4. How many vanishing points in two-point perspective?

  1. One
  2. Two
  3. Three
  4. None
Show answer
B: Two. Both on the horizon line.

5. In cabinet oblique the depth is…

  1. Doubled
  2. Full size
  3. Halved
  4. Drawn at 30°
Show answer
C: Halved. Halved to reduce distortion.
