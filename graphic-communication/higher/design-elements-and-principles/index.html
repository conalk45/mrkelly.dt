Notes

Elements and principles

TermWhat it means in a layout
LineLines that separate, lead the eye, connect or underline items
ColourUsed for mood, contrast, harmony and to link items (see Colour)
AlignmentItems lined up with each other: left, right, centre, top, bottom or justified. Always name the type
ContrastDifferences that make items stand out: colour, size, shape, weight of font, light and dark
DominanceThe item that stands out most and is seen first (the focal point), usually the largest or brightest
DepthMaking items seem to sit in front of others: layering, overlap, drop shadow, gradients
UnityItems look like they belong together: repeated colours, fonts and shapes, and grouping related items (proximity)

Higher elements and principles

TermWhat it means
ShapeGeometric or organic shapes, rotated or layered, behind text or as image frames
TextureA surface quality, real or implied, such as paper, wood or fabric backgrounds
ValueHow light or dark a colour is. High value = lots of white (light); low value = little white (dark). Low-value items stand out; high-value items recede
Mass / weightHow heavy an item looks: large, dark, bold items carry more visual weight
BalanceVisual weight spread across the layout: symmetrical (formal) or asymmetrical (informal, dynamic)
EmphasisMaking one item stand out from the rest, e.g. bold, colour, outline, white space around it
ProportionThe relative size of items: bigger items attract attention first; equal sizes give equal importance
RhythmRepetition of an element (shapes, colours, formatting, numbering) that leads the eye through the layout
White spaceEmpty space that separates items, gives a clean look and draws attention to what it surrounds
Grid structureColumns and rows that items are placed on, giving a consistent, organised layout

How to answer layout questions

  • Be specific: name the actual items. "The red heading contrasts with the black background" scores; "contrast makes it stand out" doesn't.
  • Two or more items for unity, contrast, alignment and depth: these principles are relationships between items.
  • Name the alignment type: "the body text and heading are left aligned".
  • Explain = cause + effect: "The title is the largest text (cause), so it dominates and is read first (effect)." Course reports say most candidates give only the effect.
  • Don't repeat the same point for different parts of a question.

Key terms

Dominance
The item that stands out most and is seen first.
Contrast
Differences in colour, size, shape or weight that make items stand out.
Unity
Items look like they belong together: repeated colour, font, shape.
Depth
Items appear to be in front of others: layering, overlap, drop shadow.
Alignment
Items lined up; always name the type: left, right, centre, top, bottom.
Value
Lightness or darkness: high value has more white, low value less white.
Rhythm
Repetition that leads the eye through a layout.
Proportion
Relative sizes of items, affecting what is seen first.
White space
Empty space that separates items and draws attention.
Grid structure
Columns and rows that give an organised, consistent layout.
Emphasis
Making one item stand out, e.g. with bold, colour or an outline.

Quick check

1. Which answer would score for alignment?

  1. The items are aligned
  2. The heading and body text are left aligned
  3. Alignment makes it neat
  4. It is balanced
Show answer
B: The heading and body text are left aligned. Name the type and the items.

2. The largest, brightest item that is seen first shows…

  1. Unity
  2. Dominance
  3. White space
  4. Alignment
Show answer
B: Dominance. Dominance.

3. Repeating the same font and colour across a layout creates…

  1. Contrast
  2. Unity
  3. Depth
  4. Dominance
Show answer
B: Unity. Unity.

4. A drop shadow behind an image mainly creates…

  1. Depth
  2. Rhythm
  3. Unity
  4. Alignment
Show answer
A: Depth. It lifts the image off the page.

5. Which has a HIGH value?

  1. Navy blue
  2. Pale pink
  3. Black
  4. Dark green
Show answer
B: Pale pink. High value = more white.

6. Numbered steps with the same formatting leading the eye show…

  1. Balance
  2. Rhythm
  3. Texture
  4. Mass
Show answer
B: Rhythm. Rhythm through repetition.

7. "Explain" questions need…

  1. A list of terms
  2. Cause and effect
  3. One word
  4. A sketch only
Show answer
B: Cause and effect. Cause + effect in context.
