Assemblies, constraints & file types

8 cards · 5 quiz · 0 exam

Graphic Communication · Higher · mrkellydt.co.uk

Assembly constraints

  • Mate: two faces brought together, facing each other (touching).
  • Align (flush): two faces made level, facing the same way.
  • Centre axis (axis to axis): the centre lines of two round features lined up, e.g. a pin in a hole.

Typical order: centre axis to line parts up, then mate to bring faces together, then align to finish. Use the exact terms: the 2024 N5 report says most candidates didn't give "centre axis".

Higher constraints HIGHER

  • Orientate (angle): sets the angle between parts, e.g. an arm at 20°.
  • Offset: a set distance between faces, e.g. 13 from the inner edge.
  • Tangent: a curved face touching another face.

"Fully constrained" means every part is fixed so it cannot move. Assembly questions are worth 4 marks and were more demanding than expected in 2024: state each constraint, which faces or axes, and the size.

Top-down and bottom-up modelling HIGHER

  • Bottom-up: each component is modelled separately, then inserted into an assembly and constrained. Changes must be made to each part individually.
  • Top-down: parts are modelled within the assembly, referencing each other (e.g. projecting a hole position from one part to another). Changing one part updates the related parts automatically.
  • Sub-assembly: a group of parts assembled first and then used in a bigger assembly.
  • Stock/library components: standard parts such as screws and bearings inserted from a library.

Producing drawings from CAD

CAD can generate orthographic, sectional and pictorial views straight from the 3D model, so views are always consistent and update when the model changes. Never type over a wrong dimension on a production drawing: fix the model instead. In the assignment an overridden dimension scores 0 for that component.

File types HIGHER

  • STEP and IGES: neutral 3D formats that can be opened in almost any CAD software, for sharing models between companies.
  • DXF: a 2D drawing exchange format, also a vector format.
  • 3DS: a 3D format used for rendering and animation.
  • STL files are used for 3D printing.

What catches people out

  • Wrong terms or parts not fully constrained in assembly answers. State constraint + faces/axes + size for every part until it can't move. Higher 2024
